kudo-server-go
=============

Kudo Server CPP is a Smash Online Tennis Server Emulator written in Golang. It's experimental. Not even working. It's a port of the **kudo-server-cpp** project into golang. Bit Reading is completely missing / bugged here. That's need to be fixed.

This should serve as a good starting point in porting the kudo-server into another programming language without the hassle from looking at the overly complicated C++ Source Code.
